# Roomtone 大曲库插件修正

补丁对应 `charce526/songloft-library-plus` 的 `2fefd1afb1ac342820a17560c619c615e47a7ae2` 和 `songloft-org/songloft-plugin-tag` 的 `bf97f7db5a96e0db0aafb6f3165e95b2379281b1`。保留原权限与配置；Plus 本地版本为 `0.2.16+roomtone.1`，Tag 为 `2.3.1+roomtone.10`。宿主只在远端版本更高时自动更新，同版本的构建标识不会触发覆盖；升级上游代码时仍应重新应用并验证补丁。

宿主增加可选 `songs.list({omitFingerprint:true})`，SQL 不读取指纹列，默认列表和单曲指纹读取保持兼容。Plus 每批读取 1000 首，在后台构建目录索引并提供进度，分段让出 VM；元数据缓存 15 分钟，写操作使缓存失效，外部修改可手动刷新。

标签刮削改为每页最多 100 首，通过宿主已有的歌曲分页、目录、ID 和批量查询接口读取当前页。目录树逐层展开，歌曲、校对及整理视图不再累积整库对象或一次渲染全部歌曲。校对分类和统计在服务端计算；客户端歌曲缓存最多 500 首，显式选中的歌曲单独保留。搜索、翻页和目录切换取消旧请求并忽略过期响应。目录缓存最多 16 项、30 秒，写操作使其失效。旧宿主目录接口仍会返回当前目录的直属歌曲，插件在返回浏览器之前截取当前页。

构建前在对应上游提交上运行 `git apply <补丁绝对路径>`，安装开发依赖，再执行 `pnpm exec tsc --noEmit`。验证使用 Plus builder/SDK 2.9.4、Tag builder/SDK 2.18.0。使用全新输出目录，避免重复打包旧哈希资源：

```sh
node --input-type=module -e "import {buildPlugin} from '@songloft/plugin-builder'; await buildPlugin({cwd:process.cwd(),outDir:'dist/roomtone-build'});"
node scripts/plugin-overrides/check-ui.mjs <Plus源目录> <Tag源目录>
```

通过宿主 `/api/v1/jsplugins/upload` 更新，保留旧 ZIP 以便回退，不直接修改数据库哈希或扩大权限。

2026-10-29 验证：Plus 4 项、Tag 10 项回归通过，包含完整 HTML 的 JSDOM 测试与服务端路由测试；使用 70,518 首的总量夹具，歌曲、校对和整理 DOM 均保持在 100 行以内，缓存上限、目录展开、搜索、跨页选择及过期响应均有断言。正式 leonFN 接口验证了根目录不同页、专辑目录、搜索、校对和统计，浏览器每页只接收最多 100 首。服务端查询仍可能需要数秒，不能将分页等同于查询瞬时完成。本次没有播放、刮削或写入音频标签。

前置宿主改动验证：元数据桥接测试通过；Windows 全插件测试有两项原有路径夹具失败，二者及新增测试在 leonFN Linux 容器通过。Plus 隔离全量索引约 75 秒、5,421 个节点，无 504；原音频以只读方式挂载。

2026-10-31：Tag 增加 `POST /scrape/prepare/:id`，复用指纹与文本刮削引擎，仅返回预览，不写标签、备份或已刮标记。返回具体的源错误、未配置和低匹配度原因，错误信息去除服务地址和凭证。歌曲信息对话框在用户确认后才调用宿主标签写入接口。插件 14 项、客户端相关回归及实际 NAS 只读请求验证通过；未修改真实歌曲标签，也未主动播放音频。

配置保存补充：检查 HTTP 状态及返回体；失败保留输入并显示错误，QQ 字段明确要求完整 API URL。插件回归共 18 项通过。

无名歌曲修复：先尝试音频指纹，再检查文本关键词；无关键词时不读取或写入共享空键缓存，补全信息使用识别出的歌名、歌手。22 项插件回归及类型检查通过；未播放或改写真实歌曲标签。

搜索修正：清洗曲目序号、音质及下载推广信息，支持有空格的下划线和长横线分隔，保留 Live/Remix 版本及有效标签。缺少歌手时按已有字段归一化评分。QQ 旧官方搜索地址自动使用 musicu 搜索协议，检查业务错误与响应结构，保留自定义接口参数。失败按来源显示接口错误、无候选及最高分。37 项回归和类型检查通过。leonFN 实测旧接口返回业务码 500001，新接口成功返回歌曲列表。

实机复核：插件 `3392ca1` / `2.3.1+roomtone.10` 在 leonFN 的只读预览分别从 QQ 匹配歌曲 18455（0.95）和 60781（约 0.90），元数据与音频修改时间保持不变。AcoustID 请求限制为 4 秒且不重试，失败原因单独返回并继续文字搜索，避免错误凭据或网络问题耗尽插件调用时间。

手动刮削现在返回低分候选、自动阈值和分源诊断，预览不受自动采用阈值拦截；批量刮削仍严格遵守阈值，低分结果不写共享缓存。QQ 组合搜索业务码 2001 时仅用歌名重试一次，保留原艺术家参与评分。插件 39 项测试及类型检查通过；leonFN 歌曲 53221 返回 0.57 的只读候选，元数据和音频修改时间不变。

AcoustID：读取 HTTP 400 的 JSON 错误体，错误码 4 明确提示需要 Application API Key、不能填 User API Key；参数错误与 Key 错误分开显示。设置页补充 Key 类型说明，连通性检测改用 POST，避免凭据出现在请求 URL。40 项测试和类型检查通过，leonFN 只读预览正常，配置保留。

推广元数据修正：车载音乐、推广账号等标签不能优先作为艺术家；支持清除带发布者名称的无损音质括号，从实际文件名提取歌手/歌名。咪咕 copyright 不再作为年份，songId 不再作为曲号；酷狗 Chapter 不再作为年份。43 项回归及类型检查通过。leonFN 歌曲 6581 从错误的 0.03 热门候选变为 QQ 宋祖英《浏阳河》0.95 的只读候选，未改写真实元数据或音频。

指纹标签冲突：AcoustID 高指纹相似度不等于 MusicBrainz 标签正确率。与已知歌手/歌名近乎完全不符时继续文字搜索，手动预览保留原指纹候选的冲突说明；批量自动刮削遇强冲突不写入，旧冲突 AcoustID 缓存也不直接采用。无名歌曲仍可使用指纹。修复咪咕绝对封面 URL 重复主机。插件 48 项回归及类型检查通过；leonFN 歌曲 6583 原文件重新计算指纹与库存一致，AcoustID 关联 Track 16；只读预览现返回 QQ 孙楠《风往北吹》0.95，未改写音频或标签。无法仅据此确认原音频标签和在线库哪一方有误。
