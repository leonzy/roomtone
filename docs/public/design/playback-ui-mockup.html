这几屏对应的设计决定
· 同步 vs 派对分两层表达：同步徽标在目标行（时钟），派对是单独一段（内容）。混在一起用户无法判断"为什么不同拍"。
· 派对中点即加入：内容已在多个房间响，点另一台几乎总是"也让它出声"；独占走长按。
· 没有派对总音量：房间声学不同，统一音量必然有人听不清。
· EQ 的 preamp 只读：+12dB 必削波，让用户调只会变成 bug 报告。
· 离线不给可点的高亮：置灰 + 显式"重连"，避免点了没反应。
